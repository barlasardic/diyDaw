# diyDaw Kısayolları

Bütün klavye ve fare kısayolları. "Ctrl" Linux'taki Control tuşudur. Ayrıntılı açıklamalar için
[kullanım kılavuzuna](kullanim-kilavuzu.md) bakın.

## Genel

| Kısayol | Görev |
| --- | --- |
| **Space** | Çal / durdur |
| **Tab** | Arrangement ↔ Mikser |
| **Shift+Tab** | Alt panelde Clip ↔ Device sekmesi |
| **Ctrl+Z** | Geri al |
| **Ctrl+Shift+Z** / **Ctrl+Y** | Yinele |
| **Ctrl+N** | Yeni proje |
| **Ctrl+O** | Proje aç |
| **Ctrl+S** | Kaydet |
| **Ctrl+Shift+S** | Farklı kaydet |
| **Ctrl+Shift+R** | Ses olarak dışa aktar (export) |
| **Ctrl+T** | Yeni audio track |
| **Ctrl+Shift+T** | Yeni MIDI track (synth'li) |
| **Ctrl+Alt+T** | Yeni drum track (drum rack'li) |

## Transport ve konum

| Kısayol | Görev |
| --- | --- |
| Stop düğmesi (çalarken) | Durdur |
| Stop düğmesi (dururken) | Başa sar (pattern modunda clip'in başına) |
| BPM kutusunda dikey sürükleme | Tempoyu değiştir |
| BPM kutusunda çift tık | 120 BPM |
| Konum çubuğuna tıklama / sürükleme | Konuma atla / scrub (16'lıklara yapışır) |
| … + **Alt** | Yapışmadan serbest |
| **PAT** / **SONG** | Pattern modu / şarkı modu |

## Arrangement

| Kısayol | Görev |
| --- | --- |
| Zaman cetveline tıklama | Playhead'i taşı (ızgaraya yapışır; **Alt** serbest) |
| Zaman cetvelinde dikey sürükleme | Zoom |
| **Ctrl + tekerlek** | Fare noktası etrafında zoom |
| **Tekerlek** | Dikey kaydırma (track'ler sığmıyorsa) ya da zamanda kaydırma |
| **Shift + tekerlek** | Zamanda kaydırma |
| Boş alana tıklama | Playhead'i taşı, seçimi kaldır, track'i seç |
| Clip'e tıklama | Clip'i seç |
| Clip gövdesini sürükleme | Taşı (aynı türden başka track'e de); **Alt** serbest |
| Clip kenarını sürükleme | Başını / sonunu kırp |
| **Escape** (sürüklerken) | İptal |
| **Delete** / **Backspace** | Seçili clip'i sil |
| **Ctrl+D** | Seçili clip'i çoğalt (hemen arkasına) |
| **Ctrl+E** | Seçili clip'i playhead'den böl |
| **Ctrl+L** | Seçili clip'in loop'unu aç/kapat |
| MIDI clip'e çift tık | Piano roll'da aç |
| MIDI track'te boş yere çift tık | 1 barlık yeni MIDI clip oluştur ve aç |
| Ses dosyası sürükle-bırak | Track'e clip olarak ekle (en alta: yeni track) |

## Canlı çalma (seçili MIDI track)

Sadece Ctrl/Alt/Shift basılı değilken.

| Tuş | Görev |
| --- | --- |
| `A S D F G H J K L ;` | Beyaz tuşlar (C, D, E, F, G, A, B, C, D, E) |
| `W E T Y U O P` | Siyah tuşlar (C#, D#, F#, G#, A#, C#, D#) |
| `Z` / `X` | Oktav aşağı / yukarı (başlangıç: A = C3 = MIDI 60) |
| `C` / `V` | Velocity −0,1 / +0,1 (başlangıç 0,8) |

| Kısayol | Görev |
| --- | --- |
| Düğmeyi dikey/yatay sürükleme | Değeri değiştir (değer baloncukta görünür) |

| Efekt başlığındaki yuvarlak düğme | Efekti aç / kapat (bypass) |
| **<** / **>** | Efektin sırasını değiştir |
| **x** | Efekti sil |
| **+ Add Effect** | Efekt veya eklenti ekle |
| Enstrüman başlığındaki açılır menü | Synth / Drum Rack / eklenti enstrüman |
| Drum pad'e tıklama | Pad'i seç ve dinle |
| Pad'e dosya bırakma | Pad'e sample yükle |
| **Open Editor** | Eklentinin kendi penceresini aç |
| **Master** düğmesi / mikserde master şeridine tıklama | Master efektlerini göster |
